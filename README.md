# SCRAPYTHON

## About The Project

A work-in-progress refresher project in Python, per the original project description: web scraping using different tools and libraries. The current script fetches [books.toscrape.com](https://books.toscrape.com/), saves the HTML, and parses it with BeautifulSoup to extract the book categories.

### Built With

- Python
- requests
- BeautifulSoup (bs4)

## Getting Started

### Prerequisites

- Python 3

### Installation

```sh
pip install requests beautifulsoup4
```

### Running

```sh
python main.py
```
